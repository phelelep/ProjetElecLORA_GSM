## Problématique 
Code -707 : RADIOLIB_ERR_INVALID_BUSY_STATE -> on n'arrive pas à communiquer avec le module LoRa

---

## Objectifs

Résoudre les problèmes de câblage pour communiquer avec LoRa sinon passer à la partie suivante et commencer la communication entre le module SIM7000 et ESP32 nu.

---

## Étapes de la séance 

---

### Étape 1 : Investigation

Retour d'une IA

```text
The error code is officially RADIOLIB_ERR_SPI_CMD_FAILED (-707) in current RadioLib versions. The library docs say exactly this:
"Often this means that the module is trying to use TCXO while XTAL is connected (or vice versa)."
```

### Ajout de deux condensateurs de découplage 

1. on va ajouter un condensateur chimique de 10 µF entre le VCC et le GND de la partie LoRa
2. pour plus d'efficacité on va rajouter un condensateur de 98 nF céramique en parallèle avec l'autre 

-> Résultat toujours l'erreur 707 -> RADIOLIB_ERR_SPI_CMD_FAILED

### Changement de câblage 

On va mettre le BUSY (patte 16) du Module LoRa sur le GPIO 36, et on va essayer également les GPIO 39, 33, 32 et 25 

## Résultat final après plusieurs tentatives, changements dans le code et 3 séances sans résultat. 

On n'arrive pas à communiquer avec le module LoRa la carte est detecté par le module ESP32 mais ils n'arrivement aps à communiquer -> erreur -707. toute tentation de recablage ou de changment dans le code à donne le même code erreur on va donc faire quelques changements dans notre projet.
