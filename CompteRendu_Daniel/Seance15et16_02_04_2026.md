## Étape 2 : implémenter le réveil de l'ESP32 lorsque LoRa réceptionne un message

- Nouvelle implémentation dans le code :

1. Le module LoRa réveille l’ESP32 dès qu’un message arrive (via DIO1).
2. Si aucun message n’arrive pendant 10 secondes, l’ESP32 passe en Deep Sleep (très basse consommation).
3. Au réveil, il reprend l’écoute immédiatement.
4. Si la réception est réussie, il répond avec le numéro du message + "Réception réussie".

On va utiliser le pin GPIO36 pour réveiller l'ESP32.
```cpp
#define LORA_DIO1  36
```

On va ajouter une fonction pour traiter les messages reçus.

```cpp
  // Traitement du paquet si reçu
  if (packetReceivedFlag) {
    packetReceivedFlag = false;
    lastActivity = millis();

    String received = "";
    int rxState = radio.receive(received);

    if (rxState == RADIOLIB_ERR_NONE) {
      Serial.println("\n=== MESSAGE RECEIVED ===");
      Serial.print("Msg  : "); Serial.println(received);
      Serial.print("RSSI : "); Serial.print(radio.getRSSI()); Serial.println(" dBm");
      Serial.print("SNR  : "); Serial.print(radio.getSNR()); Serial.println(" dB");
      Serial.println("-------------------");
    }

    radio.startReceive();  
  }
```

Et une fonction qui va endormir l'ESP32 si les 10 s d'inactivité sont écoulées.

```cpp
 if (millis() - lastActivity >= INACTIVITY_TIMEOUT) {
    Serial.println("\n[INFO] 10 seconds inactivity → Entering Deep Sleep...");

    delay(100);
    Serial.flush();                     // Attendre que le message soit envoyé

    // Désactiver l'action DIO1 avant de dormir
    radio.clearDio1Action();

    // Configurer le wake-up sur DIO1 (niveau HIGH)
    esp_sleep_enable_ext0_wakeup((gpio_num_t)LORA_DIO1, HIGH);

    esp_deep_sleep_start();             // L'ESP32 s'endort ici
  }

```


## Étape 3 : explication du workflow
Le module LoRa (LLCC68) envoie lui-même l’impulsion sur DIO1 dès qu’il reçoit un message valide ; on va utiliser cela pour réveiller l'ESP32.

1. Le module LoRa reçoit un message (qui a été envoyé par une autre LoRa distante) -> le paquet arrive par antenne sur le module LLCC68.
2. Le module LoRa envoie une impulsion (signal) **automatique** sur DIO1 (GPIO 36).
3. L'impulsion réveille l’ESP32 -> parce qu’on a configuré esp_sleep_enable_ext0_wakeup() sur le GPIO36.
4. L’ESP32 traite le message
5. L’ESP32 redémarre le timer d’inactivité -> lastActivity = millis();
6. Si rien n’arrive pendant 10 secondes → L’ESP32 retourne en Deep Sleep.
